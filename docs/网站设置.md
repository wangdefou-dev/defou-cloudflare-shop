# 网站设置（/admin/studio）

网站设置（/admin/studio）和经营后台（/admin）是两个独立入口，界面、菜单和管理员名单分开：经营后台管订单、发货、商品、库存、优惠券和客户；网站设置管网站本身。

| 菜单       | 用途                                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------- |
| 网站内容   | 文字、配图、常用词、模块开关、搜索引擎信息；保存即发布，10 秒内生效                                              |
| 媒体库     | 所有上传过的图片，标出被哪里使用；没在使用的可以删除                                                             |
| 支付       | 收款模式、各项 Stripe 密钥是否已配置、最近的支付回调，以及修改步骤                                               |
| 域名与站点 | 正式网址、停站状态、搜索收录、图床用量、登录保护、通知与物流服务；「全部部署设置」逐项列出代码读取的每个部署变量 |

支付密钥、域名绑定只在 Cloudflare 中修改，网站设置只显示「已配置 / 未配置」，不读取也不保存密钥。

## 权限

只有 `STUDIO_EMAIL`（Worker Secret，可写多个，逗号分隔）里的邮箱能进入，和经营后台的 `ADMIN_EMAIL` 分开；未配置时网站设置关闭（503），不会退回使用 `ADMIN_EMAIL`。网站设置位于 `/admin/studio`，接口在 `/api/admin/studio/*`，沿用经营后台现有的 Cloudflare Access 保护（`/admin*`、`/api/admin/*`），无需另配；Worker 仍独立校验 Access JWT，并按 `STUDIO_EMAIL` 而不是 `ADMIN_EMAIL` 判断权限。旧地址 `/studio` 自动跳转。

```bash
npx wrangler secret put STUDIO_EMAIL --env production
```

## 网站内容

## 分组

| 分组       | 内容                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 品牌与联系 | 店名、经营者、出品署名、产地、页脚文字、Logo、微信号与二维码、X 链接               |
| 销售季     | 开始与结束日期（决定能否下单）、顶部横条文字                                       |
| 首页       | 首屏、四个承诺、产地故事、一年的工序、商品区、更多玩法、在路上、日记区、常见问题区 |
| 各页面文案 | 下单页、订单页、商品详情页、选购指南的标题和说明                                   |
| 常见问题   | 问答列表，可增删、调整顺序                                                         |
| 配图       | 首屏大图、两款商品默认图、认领树配图、活动卡片图                                   |
| 常用词     | 商品统称、包装单位、规格名称、导航文字                                             |
| 模块开关   | 认领果树、活动赞助、配送足迹地图、日记                                             |
| 搜索引擎   | 每个页面的网页标题、描述、关键词，品牌介绍，AI 搜索说明                            |
| 修改记录   | 每次发布的版本，可恢复到任一版本                                                   |

## 规则

- 所见即所得：输入框里写什么，网站上就显示什么，没有需要记的代码或变量。修改店名、产地或经营者并保存时，会提示把网站其他地方的旧写法一起替换。
- 网页标题模板、关键词、给 AI 搜索的说明等技术项由系统按店名和商品信息自动生成，不在编辑界面里出现。
- 时间、日期、颜色、出发城市都用选择器；常见问题用「在首页显示」勾选，不用填编号。
- 关掉某个功能后，和它相关的设置项会自动隐藏。
- 上传的照片在浏览器里压缩到 1600 像素以内、清除定位等信息，再存到 R2。上传前仍需人工检查人脸、门牌和面单。
- 保存前服务端会检查格式：日期写法、主题色、图片来源、首页常见问题编号、开启的页面是否都有标题和描述。有误时不会发布，并列出问题。
- 两人同时编辑时，后保存的会提示「已被其他人修改」，刷新后再改。
- 改模块开关后后台会自动刷新，侧栏对应标签随之出现或隐藏。
- 每次发布、恢复、上传和删除图片都写入审计日志。
- 被网站内容（含历史版本）、商品、日记、返图、树照或理赔引用的图片不能删除。

## 技术说明

默认内容是 `config/store.json`；后台保存的完整内容在 D1 `site_content`，历史在 `site_content_history`（迁移 0017）。公开页每次请求由 Worker 渲染，渲染前读取内容（每个 isolate 缓存 10 秒）。新增字段时先加到 `config/store.json`，已保存的内容会自动补上新字段的默认值；需要中文名称时在 `src/components/AdminSiteContent.tsx` 的 `LABELS` 里加一行。

## 配置清单

| 类别                                                                                                  | 在哪里改                                                              |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 页面文字、配图、常见问题、常用词、模块开关、销售季日期                                                | 网站设置 → 网站内容                                                   |
| 每单上限、坏果赔付、赞助人数与日期、日报时间、统计与验证码、首屏视频、公众号二维码、地图出发城市      | 网站设置 → 网站内容                                                   |
| 暂停接单、店铺公告、偏远运费                                                                          | 网站设置 → 接单与运费                                                 |
| 商品名称、价格、规格、商品图、库存、上下架                                                            | 经营后台 → 商品 / 库存与运费                                          |
| 支付密钥与模式、域名、登录保护、管理员名单、人机验证、Telegram / 快递100 密钥与开关、停站与销售总开关 | 部署设置（wrangler.jsonc 或 `wrangler secret put`），网站设置只读显示 |

首屏视频、客服微信、公众号二维码、统计和站长验证码也可以用同名部署变量（`HERO_VIDEO_URL`、`CONTACT_WECHAT`、`OFFICIAL_QR_URL`、`GOOGLE_ANALYTICS_ID`、`CLOUDFLARE_ANALYTICS_TOKEN`、`GOOGLE_SITE_VERIFICATION`、`BING_SITE_VERIFICATION`）设置，网站设置里对应项留空时生效。销售季结束日期会同时决定认领预约截止、未预约箱数寄出日期和活动赞助最晚日期（结束后若干天，可在经营规则里改）。
